# Employee Spring Boot REST API - By Varalakshmi

🚀 Day 13 of Java Backend 50 Days Challenge - REAL REST API!

## 💚 What I Built
- Created REST API with Spring Boot 3
- Connected to MySQL Database using Spring Data JPA
- Endpoints:
    - `GET /api/employees` -> Get all employees from MySQL
    - `POST /api/employees` -> Add new employee
    - `GET /api/employees/hello` -> Health check
